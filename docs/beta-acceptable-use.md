# DriftBeacon beta acceptable use

These beta terms are intentionally concise and should be professionally reviewed before any commercial launch.

Only submit repositories you are permitted to analyse.

Do not:

- deliberately abuse the service;
- attempt to bypass beta limits;
- submit malicious payloads;
- run excessive automated submissions;
- submit private credentials or tokens;
- use a report as a guarantee of security.

DriftBeacon provides automated static analysis. Findings can contain false positives and false negatives. DriftBeacon is not a substitute for professional security review.

Availability is not guaranteed during beta testing.
