# DriftBeacon tester invitation material

## Copy-paste invitation

I’m testing DriftBeacon, a tool that analyses public infrastructure repositories and prioritises what to fix to reduce production risk.

You can paste a public GitHub repository, review its Production Health report and tell me whether the recommendations would change what your team worked on.

The beta is free, reports are temporary, public to anyone with the report link, and no installation is required.

## Interview questions

1. What did you expect before running the scan?
2. Were Top priorities and the full findings explorer more useful than a standard scanner output?
3. Did anything appear incorrectly prioritised?
4. Would a weekly version of this report change your team’s work?
5. Would you connect private repositories for continuous monitoring?
